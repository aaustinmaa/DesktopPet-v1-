# Mac 代码审查与修复

2026-09-29。范围：Mac 自有 Swift 源码、聊天渲染代码、构建和运行组件脚本，以及对应测试。第三方压缩库只检查集成，不宣称逐行审计。Windows 和安装包未修改。

## 已确认并修复的 9 类问题

| 问题 | 修复 |
| --- | --- |
| 编辑记录期间自动结算改变已有番茄钟，保存恢复旧状态，导致分钟数和完成数错误 | 按字段合并用户修改与最新记录；测试复现的 15 分钟变 40 分钟已修正 |
| 保存失败仍丢弃草稿、切换日期、关闭窗口或显示成功 | 保存返回明确结果；失败保留草稿和日期，撤回未落盘的目标修改，阻止关闭和退出 |
| 导入确认期间的数据变化被覆盖，旧记录草稿可能覆盖导入结果 | 确认后检查专注/聊天状态，先保存草稿，再基于最新数据导入并备份 |
| 主文件缺失时忽略可用备份，以空数据启动 | 恢复备份并提示；备份无法读取时保留文件并报错 |
| 2 月 30 日等非法日期被转换成另一日期 | 严格校验日期格式和实际年月日 |
| 非法字符、超大整数或超出范围的输入与实际保存值不一致 | 拒绝非法/溢出输入，显示范围校正结果；清空时保持空白，离开后显示 0 |
| API 无法取消，截图阶段取消后还可能发送请求；快速重复提交有竞争窗口 | 统一取消任务，在截图/请求边界检查取消，同步占用发送状态 |
| 重连后仍可能处理旧 Codex 进程排队的输出 | 接收前校验输出所属进程，丢弃旧连接输出 |
| 构建先删旧 app，后续复制或签名失败会失去可用开发版 | 临时目录生成并验证，成功后替换；失败保留或恢复旧版 |

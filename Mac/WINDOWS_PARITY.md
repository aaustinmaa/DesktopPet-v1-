### 数据与 AI 边界

- 新任务、备忘、运行时任务与记录关联保存在 Mac 的 `app-state.json`，旧 Mac 数据无需手动迁移；旧记录默认为未关联。
- 从 Windows 导入时仍按原规则替换匹配日期，保留 Mac 任务/备忘以及同 ID 记录的任务字段；被替换日期中的 Mac 专注明细可能随导入被替换。新任务字段不回写 Windows，不提供两平台任务同步。
- 截止日期使用普通本地日历；只填日期时过了当天才算逾期，与专注记录的 21:00 换日独立。
- AI 使用 Mac 已选择的 ChatGPT/Codex 或 OpenAI API，只接收请求范围的记录时间、单次 Notes 和任务名称/说明；不发送聊天、自由备忘或截图。离线模式使用本机明确关键词建议，不模拟 AI 自然语言解析。
- AI 返回建议，不直接改数据；有歧义保留未关联。整批应用、撤销按稳定记录 ID 校验，保留分钟、Notes 和目标状态。
- 当前支持粘贴导入，没有 Google Docs 自动同步。本次只更新 Mac 开发 `.app`，Windows 开发版及两平台安装分发包不在本次范围。

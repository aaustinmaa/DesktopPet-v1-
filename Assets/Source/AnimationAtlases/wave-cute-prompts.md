# Expressive wave animation

Mode: built-in `image_gen`, transparent RGBA. The edit target was the prior `wave-v3-source.png`, now preserved at `Assets/Archive/AnimationAtlases/suwudu-wave-before-cute/wave-v3-source.png`. Its palette, slender body and hair-covered lower silhouette remain the identity reference.

The current `wave-v3-source.png` adds anticipation, wink, smiling eyes, two small wrist waves, head tilts and a content settling expression. `wave-v3.png` contains the normalized 16-frame runtime sequence; `wave-v3-preview.gif` plays it at the application's 100 ms/frame. Old runtime frames are retained under `Assets/Archive/Sprites/suwudu-wave-before-cute`.

## Registration and playback

Run `node Scripts/BuildSuWuDuActionAtlases.mjs wave-v3` with `sharp` available (or set `SHARP_MODULE`). The wave uses the median midpoint of the opaque lower 20% of the hair hem as its horizontal anchor and the hem bottom as its vertical anchor. A single sheet-wide nearest-neighbor scale preserves generated proportions and RGBA; fixed hem registration preserves the intended head dip/tilt. The reminder continues using its original crown registration and is not regenerated by this command.

All first 15 source poses are played in order, with the opening pose reused as frame 16 for a seamless boundary. This preserves the full acting sequence rather than repeating only the first eight poses. The output remains 4 × 4 cells of 362 × 362 pixels, 1448 × 1448 overall. The GIF is a preview; the application continues loading the PNG frames.
